# Nike Jooti

A creative concept project that reimagines what Nike would look like if it were born in India.

Nike Jooti blends traditional Indian footwear inspiration with modern sneaker culture, creating a crossover between heritage and streetwear. The project explores how global branding can merge with local craftsmanship through Indian textures, cultural elements, and interactive storytelling.

## About

This concept combines Indian roots with contemporary sneaker aesthetics, imagining a world where traditional craftsmanship meets modern design language.

## Features

* Interactive and immersive user experience
* Indian-inspired design elements
* Heritage × sneaker fusion
* Smooth animations and micro-interactions
* Responsive design

## Tech Stack

* React.js
* Tailwind CSS
* Framer Motion

## Inspiration

"What if Nike was born in India?"

The goal was to create a unique cultural crossover that feels familiar while introducing a fresh perspective on global and local design.
